# B-W

B-W is a 2D game developed on Godot as part of the my study of gamedev

Ремейк Cube-Squared для ПК в стилистике зернистого чёрно-белого кино

Godot 4.4. Проект Godot лежит в `b-w/`: открыть `b-w/project.godot` в редакторе, запуск F5.
