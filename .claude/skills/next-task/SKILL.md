2. Выполнить из корня репозитория:
   ```
   gh issue list --state open --limit 100 --json number,title,labels,milestone
   ```
3. Отобрать issues текущей (самой ранней открытой) вехи без метки `status: blocked` и
   `status: needs decision`; применить фильтры. Предложить до 3 вариантов: номер, заголовок,
   размер, тип. Не начинать работу самому, ждать выбора.
4. Когда задача выбрана: повесить `status: in progress`, работать по CLAUDE.md → Process.
5. Если подходящих нет, предложить сменить фильтр или показать заблокированные с причинами.
