# Sync plan

1. Из корня репозитория:
   ```
   python3 tools/sync_plan.py --github --dry-run
   ```
   Показать пользователю, что будет создано (новые метки, вехи, issues). Если ничего нового, так и сказать.
2. После подтверждения:
   ```
   python3 tools/sync_plan.py --github
   ```
3. Закоммитить `docs/plan.yaml` и `docs/PLAN.md` вместе.

## Правила

- `plan.yaml` источник плана, `PLAN.md` генерируется, руками не правится.
- Скрипт ничего не удаляет и не переименовывает: переименованная задача создаст дубликат.
  Переименовывать issue на GitHub и в yaml одновременно.
- Закрывать issues на GitHub, не через `done: true` (это только для миграции).
